M.A.N.T.I.S. Architecture Documentation

Minimalist Alert Network for Threat Intelligence System is a Zero-Dependency Host-Based Intrusion Detection System built entirely in Python Standard Library.

Project Overview: A Zero-Dependency Approach

The core objective of M.A.N.T.I.S is to prove that advanced threat detection can be achieved from first principles, writing machine learning clustering layers entirely without tools like Scikit-Learn or Pandas. It reads packets directly at OSI Layer 2 via AF_PACKET sockets and analyzes them continuously.

Core Detection Engines

1. Statistical Engine (Z-Score)
Analyzes network flow density per second. By calculating running Mean and Standard Deviation (Z-score), it automatically identifies volumetric DDoS attacks (e.g., SYN Floods) when traffic spikes beyond expected statistical boundaries.
2. Behavioral Engine (K-Nearest Neighbors & K-Means)
Operates at Layer 4 to monitor port access patterns. Using custom-built KNN and unsupervised K-Means clustering algorithms without Scikit-Learn, it detects horizontal and vertical port scanning behaviors associated with reconnaissance (e.g., Nmap).
3. Payload Inspection (Naive Bayes)
Deep Packet Inspection (DPI) at Layer 7. Parses raw packet payloads and runs text classification logic using Bayesian probability to block SQL Injection (SQLi) and Cross-Site Scripting (XSS) attack vectors before they reach the web server.
4. Reputation Engine (Bloom Filter)
An ultra-fast, memory-efficient probabilistic data structure used to check incoming IPs against a known malicious blacklist in O(k) time complexity.

Active Defense Module

When high-confidence attacks are detected, the Sensor automatically interacts with native OS firewalls (e.g., iptables) to sever the connection and drop future packets from the offending IP address autonomously.
