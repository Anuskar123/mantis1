MANTIS system design

                

                    Minimalist Alert Network for Threat Intelligence System is a host-based intrusion detection platform implemented with the Python standard library.
                


                
Design objective

                
MANTIS investigates whether common threat-detection methods can be implemented from first principles with no third-party runtime packages. The sensor captures frames at OSI Layer 2 through Linux AF_PACKET sockets, extracts network features and passes them through four focused detection engines.


                
Detection pipeline

                

                    

                        Statistical analysis
                        Traffic anomaly detection
                        Measures packet rate against a running mean and standard deviation. Sustained observations above the configured threshold identify possible volumetric DDoS traffic.
                    


                    

                        Behavioural analysis
                        Port-scan detection
                        Uses custom K-Nearest Neighbours and K-Means implementations to classify unusual port-access patterns associated with horizontal and vertical reconnaissance.
                    


                    

                        Payload classification
                        Application-layer inspection
                        Applies a Naive Bayes classifier to captured payload features to identify patterns associated with SQL injection and cross-site scripting attempts.
                    


                    

                        Reputation lookup
                        Known malicious hosts
                        Uses a memory-efficient Bloom filter to test source addresses against a configured blacklist before the remaining analysis is completed.
                    

                


                
Response and reporting

                
Each detection is assigned a severity and risk score, enriched with MITRE ATT&CK metadata where applicable, then forwarded to the local SIEM interface. If active defence is explicitly enabled, high-confidence detections can be passed to the host firewall for blocking.
