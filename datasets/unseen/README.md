# Unseen External Evaluation

Place only genuinely disjoint evaluation data here. A source is unseen only when no record from it was used for training, feature fitting, threshold selection, hyperparameter selection, or validation.

For each source, record its origin, licence, collection date, SHA-256 hash, row count, label mapping, supported MANTIS engines, and known limitations. Do not copy the current CIC-IoT2023 corpus here if it has already contributed to model development or evaluation tuning.
